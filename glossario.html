Come pubblico i nuovi libri?
  1. Aggiungi o modifica i libri nel registro.
  2. Premi Scarica HTML aggiornato: otterrai glossario.html.
  3. Apri il caricamento file su GitHub ↗, trascina il file nella cartella principale e conferma con Commit changes.
  4. Attendi l’aggiornamento di GitHub Pages e ricarica questa pagina.

Puoi aggiungere più libri alla stessa materia o scrivere una nuova materia. Conserva il file scaricato prima di chiudere la pagina.
